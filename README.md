## Sobre o projeto

O **Cafuringa** é uma plataforma web desenvolvida para apoiar a **preservação e regeneração ambiental da APA de Cafuringa**, promovendo a agricultura familiar, práticas agroecológicas e o fortalecimento econômico dos produtores locais.

A plataforma busca aproximar **produtores e comunidade**, valorizando a produção local e facilitando a comercialização direta de produtos e serviços.

### Objetivos

* Incentivar a agricultura familiar e práticas agroecológicas;
* Valorizar produtores e produtos da região;
* Facilitar a comercialização direta com a comunidade;
* Contribuir para a preservação ambiental da APA de Cafuringa;
* Fortalecer a economia e as iniciativas locais.

## Como começar

Para executar a documentação localmente, instale as dependências do projeto:

```bash
pip install -r requirements.txt
```

Em seguida, execute:

```bash
mkdocs serve
```

A documentação estará disponível em:

```text
http://localhost:8000
```
