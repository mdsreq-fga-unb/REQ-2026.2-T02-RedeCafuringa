## Critérios de Aceitação (MVP)

A tabela a seguir apresenta os requisitos funcionais selecionados para compor o MVP (Produto Mínimo Viável) da Rede Cafuringa. Para cada requisito, é apresentada a História de Usuário (HU) correspondente, mantendo a relação de um para um entre requisito funcional e história de usuário. Também são definidos os Critérios de Aceitação (CA), que estabelecem as condições que devem ser atendidas para que a funcionalidade seja considerada implementada e validada. Dessa forma, os critérios permitem verificar objetivamente se cada requisito previsto para o MVP foi atendido pela solução.

| **RF** | **Requisito Funcional** | **HU relacionada** | **Critérios de Aceitação** |
| :----- | :---------------------- | :----------------- | :------------------------- |
| **RF01** | Cadastrar perfil de consumidor | **HU01** — Como consumidor ou visitante, quero cadastrar meu perfil na plataforma, para acessar funcionalidades e interagir com produtores e experiências. | **CA01:** Qualquer pessoa sem conta (consumidor ou visitante) consegue acessar o cadastro.<br>**CA02:** O formulário exige nome, CPF, telefone, e-mail, senha e confirmação de senha.<br>**CA03:** A senha exige no mínimo 8 caracteres e confirmação idêntica.<br>**CA04:** CPF com formato ou dígitos inválidos, e-mail com formato inválido e telefone fora do padrão são rejeitados com o erro indicado no campo.<br>**CA05:** Campos obrigatórios não preenchidos impedem o cadastro e são sinalizados na tela.<br>**CA06:** O cadastro só é concluído se o usuário confirmar ser maior de 18 anos.<br>**CA07:** CPF ou e-mail já cadastrados impedem um novo cadastro e o usuário é orientado a fazer login ou recuperar o acesso (HU10).<br>**CA08:** Após o cadastro, a conta é criada automaticamente com o perfil consumidor, sem possibilidade de escolher outro perfil.<br>**CA09:** Após o cadastro, o usuário consegue fazer login com CPF e senha (HU09). |
| **RF02** | Cadastrar perfil de produtor | **HU02** — Como produtor ou responsável por uma iniciativa, quero cadastrar meu perfil de produtor, para divulgar produção, produtos e experiências. | **CA01:** Qualquer pessoa sem conta (produtor ou responsável por iniciativa) consegue acessar o cadastro de produtor.<br>**CA02:** O usuário informa a natureza do cadastro: produtor, propriedade, associação ou comunidade.<br>**CA03:** O formulário exige nome, CPF ou CNPJ (conforme a natureza), telefone, e-mail, endereço, senha e confirmação de senha.<br>**CA04:** A senha exige no mínimo 8 caracteres e confirmação idêntica.<br>**CA05:** CPF ou CNPJ inválido, e-mail com formato inválido e telefone fora do padrão são rejeitados com o erro indicado no campo.<br>**CA06:** Campos obrigatórios não preenchidos impedem o cadastro e são sinalizados na tela.<br>**CA07:** O cadastro só é concluído se o responsável confirmar ser maior de 18 anos.<br>**CA08:** CPF/CNPJ ou e-mail já cadastrados impedem um novo cadastro e o usuário é orientado a fazer login ou recuperar o acesso (HU10).<br>**CA09:** Após o cadastro, a conta é criada automaticamente com o perfil produtor.<br>**CA10:** Após o cadastro, o produtor consegue fazer login (HU09) e acessar o registro de trajetória (HU12), o cadastro de produtos (HU17) e o de experiências (HU23).<br>**CA11:** CPF/CNPJ informados não são exibidos no perfil público do produtor (HU14). |
| **RF03** | Cadastrar usuário admin | **HU03** — Como responsável pela administração, quero cadastrar usuários administradores, para permitir apoio no gerenciamento da plataforma. | **CA01:** Somente usuário logado com perfil administrador acessa o cadastro de administradores.<br>**CA02:** Consumidor, produtor ou usuário sem login não acessa a funcionalidade.<br>**CA03:** O administrador informa nome, CPF, telefone, e-mail e senha inicial do novo administrador.<br>**CA04:** CPF inválido, e-mail com formato inválido e senha com menos de 8 caracteres são rejeitados com o erro indicado no campo.<br>**CA05:** Campos obrigatórios não preenchidos impedem o cadastro e são sinalizados na tela.<br>**CA06:** CPF ou e-mail já cadastrados impedem o cadastro.<br>**CA07:** Após salvar, a conta é criada com o perfil administrador.<br>**CA08:** O novo administrador consegue fazer login com CPF e senha (HU09) e acessar as funcionalidades administrativas.<br>**CA09:** O cadastro de administrador não pode ser feito por autocadastro público. |
| **RF04** | Consultar usuários cadastrados | **HU04** — Como administrador, quero consultar os usuários cadastrados, para acompanhar e administrar os perfis existentes. | **CA01:** Somente usuário logado com perfil administrador acessa a consulta de usuários.<br>**CA02:** Consumidor, produtor ou usuário sem login não acessa a funcionalidade.<br>**CA03:** A lista exibe os usuários cadastrados com nome, perfil (consumidor, produtor ou administrador) e e-mail.<br>**CA04:** A lista é paginada quando há muitos usuários.<br>**CA05:** O administrador consegue buscar por nome ou CPF e filtrar por perfil.<br>**CA06:** Ao selecionar um usuário, o administrador visualiza seus dados cadastrais.<br>**CA07:** A senha nunca é exibida, nem em forma parcial.<br>**CA08:** Sem usuários que correspondam à busca, aparece a mensagem “Nenhum usuário encontrado”. |
| **RF09** | Autenticar usuário | **HU09** — Como usuário cadastrado, quero realizar login, para acessar funcionalidades do meu perfil. | **CA01:** O usuário cadastrado consegue entrar informando CPF e senha corretos.<br>**CA02:** Após o login, o usuário é levado à área do seu perfil.<br>**CA03:** O sistema exibe apenas as funcionalidades permitidas ao perfil (consumidor, produtor ou administrador).<br>**CA04:** Com CPF ou senha incorretos, o acesso é negado com mensagem genérica (“CPF ou senha inválidos”), sem indicar qual dado está errado.<br>**CA05:** Campos vazios ou CPF com formato inválido são sinalizados e a autenticação não é tentada.<br>**CA06:** Ao tentar acessar funcionalidade de usuário logado sem estar autenticado, o usuário é redirecionado ao login. |
| **RF10** | Recuperar acesso à conta | **HU10** — Como usuário cadastrado sem acesso, quero recuperar meu acesso, para voltar a usar a plataforma sem novo cadastro. | **CA01:** O usuário pode solicitar a recuperação informando o CPF.<br>**CA02:** O link de redefinição é enviado somente ao e-mail cadastrado na conta.<br>**CA03:** A mensagem exibida é a mesma para CPF cadastrado ou não (“Se o CPF estiver cadastrado, enviamos as instruções”), e nenhum e-mail é enviado se o CPF não existir.<br>**CA04:** O link é válido por 1 hora e só pode ser usado uma vez.<br>**CA05:** Link inválido, expirado ou já usado exibe aviso e permite solicitar novo link.<br>**CA06:** A nova senha exige mínimo de 8 caracteres e confirmação idêntica.<br>**CA07:** Após a redefinição, o login funciona com a nova senha e deixa de funcionar com a anterior.<br>**CA08:** A recuperação restabelece o acesso apenas à conta do titular. |
| **RF12** | Registrar trajetória do produtor | **HU12** — Como produtor cadastrado, quero registrar minha trajetória e atuação, para que consumidores conheçam minha história e forma de trabalho. | **CA01:** Somente o usuário com perfil produtor acessa a funcionalidade.<br>**CA02:** O produtor consegue registrar o texto de trajetória e atuação e salvá-lo.<br>**CA03:** O texto fica vinculado ao perfil do próprio produtor.<br>**CA04:** O produtor consegue editar a trajetória já registrada.<br>**CA05:** O texto salvo aparece no perfil público do produtor.<br>**CA06:** O campo não pode ficar vazio nem ultrapassar 2.000 caracteres, com mensagem de erro clara.<br>**CA07:** Um produtor não consegue alterar a trajetória de outro produtor. |
| **RF14** | Consultar perfil de produtor | **HU14** — Como consumidor ou visitante, quero consultar o perfil de um produtor, para conhecer sua trajetória e atuação antes de comprar ou solicitar experiência. | **CA01:** Consumidores e visitantes acessam o perfil sem precisar de login.<br>**CA02:** O perfil exibe nome, localização, trajetória e atuação do produtor.<br>**CA03:** O perfil lista os produtos e as experiências oferecidos pelo produtor.<br>**CA04:** CPF/CNPJ e demais dados privados não são exibidos.<br>**CA05:** Se a trajetória não foi preenchida, aparece o aviso “Este produtor ainda não registrou sua trajetória”.<br>**CA06:** A certificação só é exibida se existir (não se presume que o produtor tenha).<br>**CA07:** Perfil inexistente exibe mensagem de “perfil não encontrado”.<br>**CA08:** O perfil oferece acesso ao contato direto com o produtor (HU39). |
| **RF17** | Cadastrar produto | **HU17** — Como produtor cadastrado, quero cadastrar meus produtos, para divulgar minha produção e permitir consulta dos consumidores. | **CA01:** Somente o usuário com perfil produtor acessa o cadastro de produtos.<br>**CA02:** O produtor consegue cadastrar o produto informando nome, descrição e disponibilidade.<br>**CA03:** A foto é opcional e o cadastro conclui normalmente sem ela.<br>**CA04:** O produto é vinculado automaticamente ao produtor ou à propriedade responsável.<br>**CA05:** Campos obrigatórios não preenchidos impedem o cadastro e são indicados na tela.<br>**CA06:** Após salvar, o produto aparece no catálogo.<br>**CA07:** Consumidor ou usuário sem login não acessa o cadastro. |
| **RF21** | Consultar catálogo de produtos | **HU21** — Como consumidor ou visitante, quero consultar o catálogo de produtos, para encontrar alimentos e outros produtos oferecidos. | **CA01:** Qualquer pessoa (logada ou não) consegue consultar o catálogo.<br>**CA02:** O catálogo exibe os produtos dos produtores cadastrados na plataforma.<br>**CA03:** Cada item mostra nome, produtor responsável e imagem (se houver).<br>**CA04:** A lista é paginada quando há muitos produtos.<br>**CA05:** Sem produtos cadastrados, aparece a mensagem “Nenhum produto disponível no momento”.<br>**CA06:** Ao clicar em um produto, o usuário é levado aos detalhes (HU22). |
| **RF22** | Consultar detalhes do produto | **HU22** — Como consumidor ou visitante, quero visualizar os detalhes de um produto, para conhecer características e identificar o produtor responsável. | **CA01:** Qualquer pessoa consegue acessar os detalhes sem login.<br>**CA02:** A tela exibe nome, descrição, imagem (se houver) e disponibilidade informada.<br>**CA03:** A tela identifica o produtor responsável.<br>**CA04:** Ao clicar no produtor, o usuário vai ao perfil público dele (HU14).<br>**CA05:** A tela oferece a opção de contato direto com o responsável (HU39).<br>**CA06:** Produto inexistente exibe mensagem de “produto não |
| **RF23** | Cadastrar experiência | **HU23** — Como produtor ou responsável, quero cadastrar uma experiência, para divulgar turismo, vivências e outras atividades. | **CA01:** Somente produtor ou responsável autorizado acessa o cadastro de experiências.<br>**CA02:** É possível cadastrar a experiência informando título, descrição e local.<br>**CA03:** A experiência é vinculada ao produtor ou à propriedade participante.<br>**CA04:** Campos obrigatórios não preenchidos impedem o cadastro e são indicados na tela.<br>**CA05:** Após salvar, a experiência aparece na lista de experiências.<br>**CA06:** Consumidor ou usuário sem login não acessa o cadastro. |
| **RF25** | Consultar experiência | **HU25** — Como consumidor ou visitante, quero consultar as experiências disponíveis, para conhecer atividades e decidir meu interesse. | **CA01:** Qualquer pessoa consegue consultar as experiências sem login.<br>**CA02:** A lista exibe título, local e responsável de cada experiência.<br>**CA03:** Os detalhes mostram título, descrição, local e produtor ou propriedade responsável.<br>**CA04:** Os detalhes oferecem as opções “Solicitar pré-reserva” (HU44) e “Entrar em contato” (HU39).<br>**CA05:** Sem experiências cadastradas, aparece “Nenhuma experiência disponível no momento”. |
| **RF36** | Buscar ofertas | **HU36** — Como consumidor ou visitante, quero buscar produtos e experiências, para encontrar ofertas com mais rapidez. | **CA01:** Qualquer pessoa consegue usar a busca sem login.<br>**CA02:** A busca considera produtos e experiências cadastrados.<br>**CA03:** A busca compara o termo com nome e descrição.<br>**CA04:** A busca ignora diferença entre maiúsculas/minúsculas e acentos (“cafe” = “CAFÉ”).<br>**CA05:** Cada resultado indica se é produto ou experiência.<br>**CA06:** Ao clicar em um resultado, o usuário vai aos detalhes correspondentes.<br>**CA07:** Sem correspondência, aparece “Nenhum resultado encontrado”.<br>**CA08:** Busca com termo vazio pede que o usuário informe um termo. |
| **RF39** | Disponibilizar contato direto | **HU39** — Como consumidor ou visitante, quero entrar em contato diretamente com o responsável, para tirar dúvidas antes de comprar ou solicitar experiência. | **CA01:** A opção de contato está disponível em produto, experiência e perfil do produtor.<br>**CA02:** Usuário não logado é direcionado ao login e retorna à conversa depois.<br>**CA03:** O consumidor ou visitante consegue enviar mensagem por chat ao responsável pela oferta consultada.<br>**CA04:** Mensagem em branco não pode ser enviada.<br>**CA05:** O responsável consegue visualizar e responder a mensagem.<br>**CA06:** A resposta aparece na mesma conversa do consumidor.<br>**CA07:** O histórico da conversa fica registrado.<br>**CA08:** Apenas os dois participantes da conversa conseguem lê-la. |
| **RF44** | Solicitar pré-reserva de experiência | **HU44** — Como consumidor ou visitante, quero enviar uma solicitação de pré-reserva, para manifestar meu interesse em uma experiência. | **CA01:** Apenas usuário logado consegue enviar a solicitação (não logado é direcionado ao login).<br>**CA02:** A solicitação é feita a partir da página de uma experiência.<br>**CA03:** O formulário exige data desejada e número de participantes; mensagem é opcional.<br>**CA04:** Data no passado é rejeitada.<br>**CA05:** Número de participantes igual a zero ou negativo é rejeitado.<br>**CA06:** Campos obrigatórios não preenchidos impedem o envio e são indicados na tela.<br>**CA07:** Após o envio, a solicitação é registrada com status “Pendente”.<br>**CA08:** A tela informa que o envio **não** é uma reserva confirmada.<br>**CA09:** O responsável passa a ver a solicitação na sua lista de recebidas. |
| **RF45** | Consultar pré-reserva | **HU45** — Como consumidor ou visitante, quero consultar o status da minha pré-reserva, para acompanhar se foi recebida, respondida ou alterada. | **CA01:** Usuário logado acessa “Minhas pré-reservas”.<br>**CA02:** A lista mostra experiência, data e status atual de cada solicitação.<br>**CA03:** Ao abrir uma solicitação, aparecem os dados enviados e o status (Pendente, Aceita, Rejeitada, Alteração solicitada ou Cancelada).<br>**CA04:** A mensagem do responsável é exibida, quando houver.<br>**CA05:** Sem solicitações, aparece “Você ainda não possui pré-reservas”.<br>**CA06:** O usuário não consegue abrir solicitação de outra pessoa.<br>**CA07:** O responsável pela experiência também consegue consultar as solicitações das suas experiências e o estado delas. |
| **RF46** | Cancelar solicitação de pré-reserva | **HU46** — Como consumidor ou visitante, quero cancelar minha solicitação, para informar que não tenho mais interesse. | **CA01:** A opção “Cancelar” só aparece para solicitações com status “Pendente”.<br>**CA02:** O sistema pede confirmação antes de cancelar.<br>**CA03:** Se o usuário recusar a confirmação, a solicitação continua “Pendente”.<br>**CA04:** Após confirmar, o status passa para “Cancelada”.<br>**CA05:** O responsável é informado do cancelamento.<br>**CA06:** Solicitações Aceita, Rejeitada, Alteração solicitada ou já Cancelada não podem ser canceladas.<br>**CA07:** O usuário não consegue cancelar solicitação de outra pessoa. |
| **RF47** | Responder pré-reserva de experiência | **HU47** — Como responsável por uma experiência, quero responder às solicitações recebidas, para informar atendimento ou necessidade de alteração. | **CA01:** O responsável vê somente as solicitações das suas próprias experiências, com status e dados do solicitante.<br>**CA02:** O responsável consegue **aceitar** uma solicitação pendente, e o status passa para “Aceita”.<br>**CA03:** A pré-reserva só é considerada confirmada a partir da aceitação.<br>**CA04:** O responsável consegue **rejeitar** a solicitação, com justificativa opcional, e o status passa para “Rejeitada”.<br>**CA05:** O responsável consegue **solicitar alteração**, com mensagem obrigatória, e o status passa para “Alteração solicitada”.<br>**CA06:** A mensagem do responsável fica visível ao solicitante.<br>**CA07:** Solicitações já respondidas ou canceladas não podem ser respondidas novamente.<br>**CA08:** O responsável não consegue responder solicitações de experiências de outro responsável. |
| **RF48** | Notificar alteração de pré-reserva | **HU48** — Como consumidor ou visitante, quero ser informado quando houver alteração na minha solicitação, para acompanhar mudanças. | **CA01:** O solicitante recebe e-mail quando o responsável aceita, rejeita ou solicita alteração.<br>**CA02:** O e-mail informa nome da experiência, novo status e mensagem do responsável (se houver).<br>**CA03:** O responsável recebe e-mail quando o solicitante cancela uma solicitação pendente.<br>**CA04:** O e-mail é enviado apenas às pessoas envolvidas na solicitação.<br>**CA05:** O status exibido em “Minhas pré-reservas” já está atualizado quando o e-mail chega.<br>**CA06:** Se o envio do e-mail falhar, a alteração de status é mantida e continua visível na plataforma. |

## Critérios de Aceitação (Todos Requisitos)

A tabela a seguir apresenta o conjunto completo de requisitos funcionais da Rede Cafuringa, incluindo tanto os requisitos contemplados no MVP quanto aqueles previstos para etapas posteriores do desenvolvimento. Cada requisito está relacionado a uma História de Usuário específica, mantendo a correspondência de um para um entre RF e HU. Para cada história de usuário são definidos um ou mais Critérios de Aceitação, utilizados como condições verificáveis para determinar se a funcionalidade atende ao comportamento esperado. A tabela permite, portanto, visualizar a relação entre o que o sistema deve oferecer, a necessidade do usuário que origina cada funcionalidade e as condições utilizadas para sua validação.

| RF | Requisito Funcional | HU relacionada | Critérios de Aceitação |
|---|---|---|---|
| **RF01** | Cadastrar perfil de consumidor | **HU01 — Como consumidor ou visitante, quero cadastrar meu perfil na plataforma, para acessar funcionalidades e interagir com produtores e experiências.** | **CA01:** O sistema deve permitir o preenchimento dos dados obrigatórios do consumidor.<br>**CA02:** O sistema deve validar os dados informados antes de concluir o cadastro.<br>**CA03:** Após o cadastro válido, o sistema deve criar o perfil e informar sua conclusão. |
| **RF02** | Cadastrar perfil de produtor | **HU02 — Como produtor ou responsável por uma iniciativa, quero cadastrar meu perfil de produtor, para divulgar produção, produtos e experiências.** | **CA01:** O sistema deve permitir o preenchimento dos dados obrigatórios do produtor.<br>**CA02:** O sistema deve validar os dados informados antes de concluir o cadastro.<br>**CA03:** O perfil do produtor deve ficar disponível para utilização das funcionalidades destinadas a produtores. |
| **RF03** | Cadastrar usuário admin | **HU03 — Como responsável pela administração, quero cadastrar usuários administradores, para permitir apoio no gerenciamento da plataforma.** | **CA01:** O sistema deve permitir que um administrador cadastre outro usuário com perfil administrativo.<br>**CA02:** O sistema deve exigir os dados obrigatórios para criação da conta.<br>**CA03:** O novo usuário deve receber as permissões correspondentes ao perfil administrativo. |
| **RF04** | Consultar usuários cadastrados | **HU04 — Como administrador, quero consultar os usuários cadastrados, para acompanhar e administrar os perfis existentes.** | **CA01:** O sistema deve apresentar a relação de usuários cadastrados ao administrador.<br>**CA02:** A consulta deve apresentar informações suficientes para identificar cada usuário.<br>**CA03:** Usuários sem registros devem receber uma indicação de que não há resultados. |
| **RF05** | Desativar usuário | **HU05 — Como usuário cadastrado, quero realizar login, para acessar funcionalidades do meu perfil.** | **CA01:** O sistema deve permitir a autenticação utilizando credenciais válidas.<br>**CA02:** Credenciais inválidas não devem conceder acesso à área autenticada.<br>**CA03:** Após autenticação válida, o usuário deve ser direcionado às funcionalidades disponíveis para seu perfil. |
| **RF06** | Consultar conteúdos cadastrados | **HU06 — Como usuário cadastrado sem acesso, quero recuperar meu acesso, para voltar a usar a plataforma sem novo cadastro.** | **CA01:** O sistema deve permitir iniciar a recuperação de acesso a partir da tela de autenticação.<br>**CA02:** A recuperação deve utilizar o meio de contato cadastrado pelo usuário.<br>**CA03:** O sistema deve permitir a definição de uma nova credencial após a validação da solicitação. |
| **RF07** | Remover conteúdo inadequado | **HU07 — Como produtor cadastrado, quero registrar minha trajetória e atuação, para que consumidores conheçam minha história e forma de trabalho.** | **CA01:** O produtor deve conseguir registrar informações sobre sua trajetória e atuação.<br>**CA02:** O sistema deve permitir salvar as informações preenchidas.<br>**CA03:** As informações salvas devem ser apresentadas no perfil do produtor quando aplicável. |
| **RF08** | Atualizar informações institucionais | **HU08 — Como consumidor ou visitante, quero consultar o perfil de um produtor, para conhecer sua trajetória e atuação antes de comprar ou solicitar experiência.** | **CA01:** O sistema deve permitir a consulta do perfil público de um produtor.<br>**CA02:** O perfil deve apresentar as informações disponibilizadas pelo produtor.<br>**CA03:** O consumidor deve conseguir acessar o perfil a partir de uma oferta relacionada ao produtor. |
| **RF09** | Autenticar usuário | **HU09 — Como produtor cadastrado, quero cadastrar meus produtos, para divulgar minha produção e permitir consulta dos consumidores.** | **CA01:** O produtor autenticado deve conseguir iniciar o cadastro de um produto.<br>**CA02:** O sistema deve exigir os campos obrigatórios definidos para o produto.<br>**CA03:** Após o cadastro válido, o produto deve ser associado ao produtor responsável. |
| **RF10** | Recuperar acesso à conta | **HU10 — Como consumidor ou visitante, quero consultar o catálogo de produtos, para encontrar alimentos e outros produtos oferecidos.** | **CA01:** O sistema deve apresentar os produtos disponíveis para consulta.<br>**CA02:** Cada produto deve apresentar informações suficientes para sua identificação.<br>**CA03:** O catálogo deve permitir ao usuário acessar os detalhes de um produto. |
| **RF11** | Excluir conta | **HU11 — Como consumidor ou visitante, quero visualizar os detalhes de um produto, para conhecer características e identificar o produtor responsável.** | **CA01:** O sistema deve apresentar os detalhes cadastrados do produto.<br>**CA02:** A página deve identificar o produtor responsável pela oferta.<br>**CA03:** O usuário deve conseguir acessar o perfil do produtor a partir dos detalhes do produto. |
| **RF12** | Registrar trajetória do produtor | **HU12 — Como produtor ou responsável, quero cadastrar uma experiência, para divulgar turismo, vivências e outras atividades.** | **CA01:** O responsável deve conseguir cadastrar uma experiência.<br>**CA02:** O sistema deve exigir as informações obrigatórias da experiência.<br>**CA03:** Após o cadastro, a experiência deve ficar disponível para consulta conforme suas condições de publicação. |
