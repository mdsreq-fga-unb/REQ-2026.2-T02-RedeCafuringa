## 2. História de Usuário

*Como consumidor ou visitante, quero filtrar as ofertas disponíveis na plataforma de acordo com os critérios disponibilizados, para refinar os resultados e encontrar produtos, experiências e eventos que atendam às minhas necessidades e preferências.*

---

## 3. Critérios de Aceitação

**CA01 — Acessar os filtros de ofertas**

- **Dado** que o usuário esteja visualizando as ofertas disponíveis na plataforma **quando** acessar a funcionalidade de filtragem, **então** o sistema deve disponibilizar os critérios de filtragem definidos para as ofertas.

**CA02 — Selecionar critérios de filtragem**

- **Dado** que o sistema tenha disponibilizado os filtros, **quando** o usuário selecionar um ou mais critérios, **então** o sistema deve permitir a aplicação dos critérios escolhidos.

**CA03 — Filtrar ofertas por critérios selecionados**

- **Dado** que existam ofertas cadastradas na plataforma, **quando** o usuário aplicar os critérios de filtragem selecionados, **então** o sistema deve apresentar somente as ofertas que correspondam aos critérios informados.

**CA04 — Combinar diferentes filtros**

- **Dado** que o sistema disponibilize diferentes critérios de filtragem, **quando** o usuário selecionar mais de um critério, **então** o sistema deve considerar conjuntamente os critérios selecionados na filtragem das ofertas.

**CA05 — Apresentar resultados filtrados**

- **Dado** que existam ofertas correspondentes aos critérios selecionados, **quando** a filtragem for concluída, **então** o sistema deve apresentar os resultados encontrados de forma organizada.

**CA06 — Tratar filtragem sem resultados**

- **Dado** que não existam ofertas correspondentes aos critérios selecionados, **quando** o usuário aplicar os filtros, **então** o sistema deve informar que nenhuma oferta foi encontrada para os critérios escolhidos.

**CA07 — Remover critérios de filtragem**

- **Dado** que o usuário tenha aplicado um ou mais filtros, **quando** remover um critério selecionado, **então** o sistema deve atualizar os resultados considerando os critérios restantes.

**CA08 — Limpar todos os filtros**

- **Dado** que o usuário tenha aplicado filtros às ofertas, **quando** selecionar a opção de limpar filtros, **então** o sistema deve remover todos os critérios aplicados e apresentar novamente as ofertas sem filtragem.

**CA09 — Permitir filtragem sem autenticação**

- **Dado** que o usuário não esteja autenticado, **quando** acessar a funcionalidade de filtragem, **então** o sistema deve permitir a aplicação de filtros e a consulta das ofertas públicas.

## 4. Relação com os Requisitos Não Funcionais

**[RNF01 — Eficiência de Navegação](../requisitos_software.md#72-requisitos-nao-funcionais)**

A funcionalidade deve facilitar o refinamento dos resultados e permitir que o usuário encontre ofertas de interesse com poucas etapas de navegação.

**[RNF02 — Tempo de Execução de Tarefas](../requisitos_software.md#72-requisitos-nao-funcionais)**

A aplicação dos filtros e a atualização dos resultados devem atender ao tempo máximo estabelecido para execução da tarefa.

**[RNF03 — Prevenção e Recuperação de Erros](../requisitos_software.md#72-requisitos-nao-funcionais)**

O sistema deve orientar o usuário diante de situações em que os filtros selecionados não produzam resultados e permitir a alteração ou remoção dos critérios aplicados.

**[RNF04 — Acessibilidade Digital](../requisitos_software.md#72-requisitos-nao-funcionais)**

Os controles de filtragem e a apresentação dos resultados devem ser acessíveis e compreensíveis para diferentes usuários.

**[RNF05 — Responsividade da Interface](../requisitos_software.md#72-requisitos-nao-funcionais)**

A funcionalidade de filtragem deve se adaptar aos diferentes tamanhos de tela, mantendo a disponibilidade e a usabilidade dos controles.

**[RNF06 — Desempenho em Conectividade Limitada](../requisitos_software.md#72-requisitos-nao-funcionais)**

A aplicação dos filtros e a atualização dos resultados devem considerar as condições de conectividade previstas para a plataforma.

**[RNF12 — Compatibilidade entre Navegadores](../requisitos_software.md#72-requisitos-nao-funcionais)**

A funcionalidade de filtragem deve funcionar nos navegadores contemplados pelo requisito.
