## 2. História de Usuário

*Como consumidor, quero enviar um feedback sobre um fornecedor, para registrar minha experiência e contribuir para a melhoria das relações entre consumidores e produtores.*

---

## 3. Critérios de Aceitação

**CA01 — Acessar funcionalidade de feedback**

* **Dado** que o usuário esteja autenticado, **quando** acessar a área de feedback de um fornecedor, **então** o sistema deve disponibilizar a funcionalidade de envio de feedback conforme as permissões do perfil.

**CA02 — Preencher feedback**

* **Dado** que o usuário esteja na funcionalidade de feedback, **quando** preencher as informações solicitadas, **então** o sistema deve permitir o envio do conteúdo informado.

**CA03 — Validar preenchimento**

* **Dado** que existam campos obrigatórios no formulário, **quando** o usuário tentar enviar o feedback sem preenchê-los, **então** o sistema deve informar quais informações precisam ser corrigidas.

**CA04 — Enviar feedback**

* **Dado** que o usuário tenha preenchido corretamente as informações solicitadas, **quando** confirmar o envio, **então** o sistema deve registrar o feedback associado ao fornecedor correspondente.

**CA05 — Confirmar envio**

* **Dado** que o feedback tenha sido registrado com sucesso, **quando** o processamento for concluído, **então** o sistema deve informar ao usuário que o envio foi realizado.

**CA06 — Preservar privacidade do feedback**

* **Dado** que o usuário envie um feedback, **quando** o sistema armazenar e disponibilizar as informações, **então** deve respeitar as condições de privacidade estabelecidas para o feedback.

**CA07 — Tratar falha no envio**

* **Dado** que ocorra uma falha durante o envio, **quando** o sistema tentar registrar o feedback, **então** deve informar que a operação não foi concluída e permitir que o usuário tente novamente.

---

## 4. Relação com os Requisitos Não Funcionais

**RNF03 — Prevenção e Recuperação de Erros**

* Relação com a HU: o sistema deve orientar o usuário diante de preenchimentos inválidos ou falhas no envio do feedback.

**RNF04 — Acessibilidade Digital**

* Relação com a HU: os campos e orientações do formulário devem ser acessíveis e compreensíveis.

**RNF05 — Responsividade da Interface**

* Relação com a HU: o formulário de feedback deve funcionar adequadamente em diferentes tamanhos de tela.

**RNF08 — Controle de Acesso por Perfil**

* Relação com a HU: o envio de feedback deve respeitar as permissões previstas para o perfil do usuário.

**RNF09 — Privacidade do Feedback**

* Relação com a HU: o conteúdo enviado deve respeitar as condições de privacidade definidas para o feedback, sem exposição indevida.

**RNF10 — Proteção da Comunicação**

* Relação com a HU: o envio e o armazenamento das informações devem ocorrer por meio de comunicação protegida.

**RNF11 — Proteção de Dados Pessoais**

* Relação com a HU: os dados pessoais associados ao feedback devem ser tratados conforme sua finalidade, evitando exposição indevida.

## 5. Relação com as Regras de Negócio

**RN18 — Feedback privado**

* Relação com a HU: estabelece as condições de privacidade aplicáveis aos feedbacks enviados pelos usuários sobre os fornecedores.
