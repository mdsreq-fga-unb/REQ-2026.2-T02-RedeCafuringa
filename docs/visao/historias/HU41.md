## 2. História de Usuário

*Como usuário autorizado, quero visualizar os feedbacks relacionados a um fornecedor, para consultar as informações registradas e acompanhar as experiências compartilhadas na plataforma.*

---

## 3. Critérios de Aceitação

**CA01 — Acessar feedbacks**

- **Dado** que o usuário esteja autenticado, **quando** acessar a funcionalidade de visualização de feedback, **então** o sistema deve apresentar os feedbacks aos quais o perfil possui permissão de acesso.

**CA02 — Consultar feedback de fornecedor**

- **Dado** que existam feedbacks associados a um fornecedor, **quando** o usuário autorizado acessar a área correspondente, **então** o sistema deve apresentar os registros disponíveis para consulta.

**CA03 — Respeitar privacidade**

- **Dado** que os feedbacks estejam sujeitos a regras de privacidade, **quando** o sistema apresentar os registros, **então** deve respeitar as permissões de visualização e não expor informações privadas indevidamente.

**CA04 — Restringir acesso não autorizado**

- **Dado** que o usuário não possua permissão para visualizar determinado feedback, **quando** tentar acessar o registro, **então** o sistema deve impedir a visualização do conteúdo restrito.

**CA05 — Tratar ausência de feedback**

- **Dado** que não existam feedbacks disponíveis para consulta, **quando** o usuário acessar a funcionalidade, **então** o sistema deve informar que não há registros disponíveis.

**CA06 — Apresentar informações corretamente**

- **Dado** que existam feedbacks disponíveis para visualização, **quando** o sistema apresentar os registros, **então** deve exibir as informações armazenadas sem alterar seu conteúdo.

## 4. Relação com os Requisitos Não Funcionais

**[RNF04 — Acessibilidade Digital](../requisitos_software.md#72-requisitos-nao-funcionais)**

**[RNF05 — Responsividade da Interface](../requisitos_software.md#72-requisitos-nao-funcionais)**

Garante que a visualização dos feedbacks funcione adequadamente em diferentes tamanhos de tela e dispositivos.

**[RNF08 — Controle de Acesso por Perfil](../requisitos_software.md#72-requisitos-nao-funcionais)**

Garante que a consulta aos feedbacks respeite rigorosamente as permissões associadas ao perfil de cada usuário.

**[RNF09 — Privacidade do Feedback](../requisitos_software.md#72-requisitos-nao-funcionais)**

Assegura que a visualização respeite as condições de privacidade definidas para os registros de feedback, evitando exposições indevidas.

**[RNF11 — Proteção de Dados Pessoais](../requisitos_software.md#72-requisitos-nao-funcionais)**

Garante que informações pessoais eventualmente associadas aos feedbacks sejam tratadas com segurança e não sejam expostas de forma incorreta.

**[RNF12 — Compatibilidade entre Navegadores](../requisitos_software.md#72-requisitos-nao-funcionais)**
