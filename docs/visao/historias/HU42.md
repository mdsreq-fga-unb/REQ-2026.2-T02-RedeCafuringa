## 2. História de Usuário

*Como usuário que enviou um feedback, quero editar o conteúdo registrado, para corrigir ou atualizar as informações compartilhadas sobre minha experiência com um fornecedor.*

---

## 3. Critérios de Aceitação

**CA01 — Acessar feedback próprio**

* **Dado** que o usuário esteja autenticado, **quando** acessar seus feedbacks enviados, **então** o sistema deve apresentar os registros associados à sua conta.

**CA02 — Selecionar feedback para edição**

* **Dado** que o usuário possua um feedback registrado, **quando** selecionar a opção de edição, **então** o sistema deve permitir a alteração do conteúdo, respeitando as permissões estabelecidas.

**CA03 — Apresentar conteúdo atual**

* **Dado** que o usuário tenha selecionado um feedback para edição, **quando** o formulário de edição for apresentado, **então** o sistema deve carregar as informações atualmente registradas.

**CA04 — Validar alterações**

* **Dado** que o usuário tenha alterado o conteúdo do feedback, **quando** tentar salvar as alterações, **então** o sistema deve validar os campos obrigatórios e informar eventuais inconsistências.

**CA05 — Salvar alterações**

* **Dado** que as informações alteradas sejam válidas, **quando** o usuário confirmar a edição, **então** o sistema deve atualizar o feedback correspondente.

**CA06 — Restringir edição de terceiros**

* **Dado** que o feedback pertença a outro usuário, **quando** alguém tentar editá-lo sem possuir autorização, **então** o sistema deve impedir a alteração.

**CA07 — Tratar falha na edição**

* **Dado** que ocorra uma falha durante o salvamento, **quando** o usuário tentar atualizar o feedback, **então** o sistema deve informar que a alteração não foi concluída e preservar o registro anterior.

## 4. Relação com os Requisitos Não Funcionais

**[RNF03 — Prevenção e Recuperação de Erros](../requisitos_software.md#72-requisitos-nao-funcionais)**

Garante que o sistema valide as alterações e oriente o usuário de forma clara diante de erros, preservando o conteúdo anterior quando a atualização não for concluída.

**[RNF04 — Acessibilidade Digital](../requisitos_software.md#72-requisitos-nao-funcionais)**

Garante que os campos e orientações da edição sejam acessíveis e compreensíveis a usuários com diferentes necessidades.

**[RNF05 — Responsividade da Interface](../requisitos_software.md#72-requisitos-nao-funcionais)**

Garante que o formulário de edição funcione adequadamente em diferentes tamanhos de tela e dispositivos.

**[RNF08 — Controle de Acesso por Perfil](../requisitos_software.md#72-requisitos-nao-funcionais)**

Garante que a edição seja permitida somente ao usuário autorizado, respeitando estritamente as permissões do perfil.

**[RNF09 — Privacidade do Feedback](../requisitos_software.md#72-requisitos-nao-funcionais)**

Assegura que o conteúdo do feedback continue protegido durante todo o processo de edição.

**[RNF11 — Proteção de Dados Pessoais](../requisitos_software.md#72-requisitos-nao-funcionais)**

Garante que os dados pessoais associados ao feedback permaneçam protegidos durante a atualização.
