# Evidências da Iteração 6

## Declaração de Requisitos    

### Requisito de Negócio
Não houve nenhum tipo de nova técnica utilizada na declaração de requisitos de negócio nesta fase do projeto.

### Requisito de Usuário - Oriantadas a Valor
As histórias de usuário permanecem como a técnica utilizada para os requisitos de usuário na fase de construção. Não houve alterações nesses critérios desde a fase de elaboração.

### Requisito de Produto - Declarações Estruturadas
Os critérios de aceitação permanecem como a técnica utilizada para os requisitos de produto na fase de construção. Não houve alterações nesses critérios desde a fase de elaboração.
